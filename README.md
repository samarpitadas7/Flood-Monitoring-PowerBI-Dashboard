📊 Power BI Data Analysis Dashboard

📌 Overview

This project focuses on transforming a dataset into an interactive and visually engaging dashboard using Microsoft Power BI.

The dashboard provides an easy way to explore the data through interactive visualizations, KPIs, filters, and maps.

✨ Dashboard Features

- 📌 Interactive KPI Cards
- 📊 Charts and visualizations
- 🗺️ Map-based analysis
- 🔎 Interactive filters and slicers
- 📈 Data categorization
- 🎯 Easy-to-understand visual insights

🛠️ Tools & Technologies

- Microsoft Power BI
- Data Analysis
- Data Visualization
- Data Cleaning & Transformation

📂 Repository Contents

- "dashboard/" – Power BI dashboard file
- "dataset/" – Dataset used for the analysis
- "screenshots/" – Dashboard screenshots
